# Contributing

1. Create a feature branch.
2. Keep changes focused and update tests with behavior changes.
3. Run `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run assets:check`, and `npm run test:e2e`.
4. Open a pull request against `main`; merge only after CI passes.

Do not commit `dist/`, `node_modules/`, source art, credentials, or generated test reports.
